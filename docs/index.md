# Isogate Documentation

Isogate is an inspectable deterministic computing ecosystem combining a browser virtual CPU, bounded Native Node workloads, canonical server recomputation, public verification records, and CPU-generated Genesis assets on Robinhood Chain.

## Current boundary

Isogate is a technical beta. Native Node executes only built-in bounded workloads, result acceptance uses canonical server recomputation, and Genesis requires creator-signed on-chain transactions. Isogate does not claim arbitrary remote execution, a permissionless verifier network, or guaranteed market value.
