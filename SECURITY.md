# Security policy

## Scope

This repository contains public documentation only. It does not contain
application code, smart-contract source, deployment credentials, private keys,
database contents, or production data. Reports about a live service, package,
contract, or network integration are still welcome.

## Reporting a vulnerability

Please email [support@isogate.tech](mailto:support@isogate.tech) rather than
opening a public issue. Include a concise description, affected component,
reproduction steps or a minimal proof of concept, potential impact, and a safe
way to contact you.

Never include wallet private keys, provider credentials, API tokens, personal
data, or other secrets in a report. If sensitive attachments are necessary,
ask for a secure delivery method first.

## Disclosure

We will acknowledge a report when practical, investigate its impact, and
coordinate remediation and public disclosure with the reporter. Do not perform
denial-of-service activity, access accounts or data that do not belong to you,
or interact with production systems beyond what is necessary to demonstrate the
issue.

The documentation describes a technical beta and makes no security, market,
audit, or financial guarantee.
